# Kiro에 보낼 인계 프롬프트 (각자 첫 메시지)

docs/ 폴더가 우리 팀이 직접 확정한 설계다:
00(스택·제약) / 01(요구사항 P0·P1·제외) / 02(API 계약) / 03(DB 스키마) /
04(판정 룰표) / 05(설계 상세) / 06(작업 명세)

- 설계 내용(스택, API, 필드명, 스키마, 룰 수치)의 변경 제안은 금지
- 문서에 없는 세부사항만 질문해줘
- docs/06의 내 담당 task를 순서대로 한 번에 하나씩만 진행하고,
  각 task의 완료 조건을 확인한 뒤 결과를 보고해줘
