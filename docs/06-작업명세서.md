## P0 Frontend — static/ (현재 작업. 계약은 .kiro/steering/api-contract.md 기준)

화면 4개다: ①제출(업로드+수동입력) ②미분류 정리 ③내역 목록 ④판결 결과

### 기반
- TASK-F001 공통 스타일 + fetch 헬퍼
  응답 봉투 `{success, data}`를 벗기고, 실패면 `error.message`를 그대로 띄우는 헬퍼 하나.
  **DELETE 성공 응답에는 data가 없다**(`{"success": true}`)는 점에 주의.
- TASK-F002 피고인 이름 입력 (10자 이내). 입력한 이름을 브라우저에 기억해두고
  업로드·저장·분석 요청에 함께 보낸다. 안 넣어도 동작해야 한다(서버가 기본값을 채운다).

### 제출 화면
- TASK-F003 파일 업로드 UI — 엑셀·CSV·PDF 선택, `POST /api/import?dryRun=true`로 먼저 파싱.
  **8초쯤 걸린다.** 로딩 문구·버튼 비활성화·연타 방지 필수.
- TASK-F004 파싱 결과 확인 화면 — items를 표로 보여주고, 확정하면 dryRun 없이 재호출해 저장.
  `warning`이 null이 아니면 안내를 띄운다(스캔 PDF는 items가 빈 배열).
- TASK-F005 수동 입력 폼 — 상호명/날짜/금액/카테고리/거래유형. 카테고리 셀렉트는
  **화면에 한글 라벨, 값은 영문 코드**. 저장 성공은 **201**이다(res.ok로 판정).

### 미분류 정리 화면
- TASK-F006 업로드 응답의 `needsReviewCount`가 0보다 크면 정리 화면으로 유도한다.
- TASK-F007 미분류 목록 — `needsReview: true`인 건만 모아 보여준다.
  각 행에 **메모 입력(10자 이내)** + **카테고리 선택**을 나란히 배치.
- TASK-F008-1 **[건너뛰기] 버튼** — `POST /api/expenses/skip-review?month=`.
  미분류가 많을 때 하나씩 못 쓰는 사람을 위한 탈출구다. 누르면 전부 '기타'로 확정되고
  판결문에 논평이 붙는다는 걸 버튼 옆에 한 줄로 알려줄 것.
- TASK-F008 정리 저장 — `PUT /api/expenses/{id}`로 보낸다.
  **PUT이 성공하면 서버가 needsReview를 자동으로 내린다.** 별도 해제 요청 불필요.

### 내역 목록 화면
- TASK-F009 월 선택 (기본 현재 월, YYYY-MM으로 전달)
- TASK-F010 목록 — 날짜·상호명·금액·카테고리·거래유형·메모.
  **목록 응답에는 한글 라벨이 없다.** category 코드를 프론트 매핑표로 바꿔 표시할 것.
- TASK-F011 수정 UI / TASK-F012 삭제 UI (삭제 응답에 data 없음)

### 판결 결과 화면 (핵심)
- TASK-F013 분석 API 연결 — `GET /api/analysis?month=&defendant=`.
  **5초쯤 걸린다.** 로딩 문구("법정 개정 중...") 필수.
- TASK-F014 총지출 카드 / TASK-F015 카테고리 통계 (CSS progress bar면 충분)
  categoryStats에는 `label`이 들어있다. 여기선 그대로 쓰면 된다.
- TASK-F016 **판결문 UI** — 피고인 이름·죄명·증거·판결·이유·형량. 결과 화면의 핵심, 크게.
- TASK-F017 소비 유형 배너 (클릭 가능)
- TASK-F018 MZ 메시지 팝업 (배너 클릭 → reactionMessage 표시)
- TASK-F019-1 **기타 논평** — `remark`가 null이 아니면 `remark.message`를 판결문 아래에
  띄운다. `level`이 severe면 강조 색.
- TASK-F019 **공공데이터 비교** — MZ 메시지 아래에 `benchmark.headline`을 띄우고,
  그 밑에 작은 글씨로 `benchmark.source`를 표기한다(공공데이터 인용이라 출처 필수).
  `isEstimated`가 true면 "추정" 표기를 덧붙인다. `benchmark`가 null이면 영역을 숨긴다.

**금지: 프론트에서 합계·비율·평균을 다시 계산하지 말 것. 소비 유형도 재계산 금지.**
서버가 준 값을 그대로 렌더한다. 다시 구하면 판결문과 통계가 어긋난다.
