# 스택 결정 + 환경 제약

## ✅ 확정 스택 (8/28 새벽 팀 결정)
- **Frontend: 순수 HTML + CSS + JavaScript** (React 폐기 — 빌드 체인 제거, FastAPI가 정적 서빙, 시안 재현 유리)
- **Backend: FastAPI (Python) + SQLite(내장 sqlite3)** (서버에 파이썬 환경 완비·boto3 검증됨 → 최고 속도)
- **AI: Bedrock Claude** — 호출 지점 2곳 (그 외로 늘리지 않는다)
  1. 판결문 "이유+형량" 생성 (죄명·주문·소비유형 판정은 룰/템플릿)
  2. 업로드한 지출내역 파일의 표준 JSON 정규화·카테고리 분류·미분류 판단
  둘 다 실패 시 폴백이 있어 빈 화면이 되지 않는다. 로컬은 MOCK_AI=1
- **공공데이터 2종**: ①소상공인 상권정보(277만 상가) 색인 → OTHER 카테고리 오프라인 재보정
  ②국가데이터처 1인가구 통계 → 소비 비교(benchmark). 색인은 커밋 안 하고 서버에 scp
- **Server: EC2 + nohup + 포트 8501** (배포 시 기존 Streamlit 프로세스 종료)
