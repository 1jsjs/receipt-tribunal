# DB 스키마 (SQLite 파일 1개: data/database.sqlite — 커밋 금지)

## 테이블: expenses
| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | INTEGER | PK AUTOINCREMENT | 고유 ID |
| store_name | TEXT | NOT NULL | 상호명 (API: storeName) |
| date | TEXT | NOT NULL | YYYY-MM-DD 문자열 그대로 |
| amount | INTEGER | NOT NULL | 원 단위 정수 |
| category | TEXT | NOT NULL | 6종 코드 |
| transaction_type | TEXT | NOT NULL | EXPENSE / TRANSFER |
| created_at | TEXT | NOT NULL | 생성 시각 |
| updated_at | TEXT | NOT NULL | 수정 시각 |

## 규칙
- DB=snake_case, API=camelCase — 변환은 백엔드에서만 (프론트는 DB 컬럼명 모름)
- 테이블 1개로 MVP 전체 커버 (users/verdicts 없음 — 로그인 없음, 판결은 매번 계산)
- CREATE TABLE IF NOT EXISTS — 재시작 시 데이터 보존
