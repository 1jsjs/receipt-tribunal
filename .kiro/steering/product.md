# 제품 정의 — 영수증 소비 재판소

## 한 줄
한 달치 지출내역을 제출하면, 통장이 나를 고소하고 재판부가 판결문을 선고하는 서비스.

## 핵심 흐름 (이 연결의 자연스러움이 최우선 목표)
피고인 이름 입력 → 통장 내역 파일 업로드 → "어? 배달을 이렇게 많이?"
→ 정체 모를 항목 몇 건 정리(또는 건너뛰기) → 재판
→ "피고인 박진수, 냉장고 유기죄" → 유형 배너 클릭 → "ㅋㅋ루삥뽕" → ㅋㅋㅋㅋ

## 화면 4개 (⚠️ 아직 안 만들어짐 — 프론트가 만들 목표 사양. 백엔드 API는 전부 준비됨)
1. **홈 = 달력** — 이번 달 총지출 + 월 달력. 날짜 칸에 -지출(빨강)/+수입(초록) 합계,
   날짜 클릭 → 그 날 거래 목록·수정·직접 입력. 파일 업로드는 거래의 원본 날짜대로 자동 분배됨.
   다음 달이 되면 "지난달 판결문 보기" 배너(프론트 날짜 체크)
1-1. **제출** — 피고인 이름(10자) · 파일 업로드(미리보기 후 확정) · 수동 입력
2. **미분류 정리** — 상호명 대신 예금주 이름만 있는 건에 메모(10자)+카테고리 지정,
   또는 [건너뛰기]로 전부 기타 확정
3. **목록** — 월 선택 · 수정 · 삭제
4. **판결 결과** — 통계 · 판결문 · 유형 배너 · MZ 팝업 · 공공데이터 비교 · 행방불명 논평

## 화면 중요도 (큰 것이 위)
소비 유형 > 판결문 > 총지출 > 카테고리별 > 세부 통계
결과 화면이 이 서비스의 전부다. 판결문은 크고 눈에 띄게.

## 절대 제거 금지
파일 업로드 / 수동 입력 / 저장 / 월별 조회 / 수정 / 삭제 /
미분류 정리 + 건너뛰기 / 월간 분석 / 소비 유형 판정 /
판결문(피고인명·죄명·증거·판결·이유·형량) / MZ 배너 클릭

## 톤
- 재판소 컨셉: 존댓말 판사 어조, 진지한 척하지만 내용은 웃김
- MZ 리액션은 반대로 완전 구어체("ㅋㅋ루삥뽕", "ㄹㅇ")
- 에러 문구도 서비스 톤으로("판결을 원하시면 소비 내역부터 제출하세요 👨‍⚖️")
- **판결 대상은 소비 습관이지 사용자 자신이 아니다.** 인신공격·죄책감 유발 금지
- **단정하지 않는다.** 예금주 송금은 채무일 수도 정산일 수도 용돈일 수도 있다.
  "채무관계가 의심되나 증거 불충분"처럼 재판 톤으로 여지를 남기는 편이 사실에도 맞고 더 웃긴다

## 데이터 정직성 (심사에서 물어볼 수 있다)
- 공공데이터 비교의 **총액·비목 비중은 공표 수치**지만, 우리 6종 카테고리로의
  **배분은 추정**이다. `isEstimated: true`이며 화면에 "추정" 표기가 나간다.
- 20대만 뽑은 수치는 쓰지 않는다. KOSIS에 1인가구×연령대 교차표가 공표돼 있지 않아
  "전국 1인가구 평균"으로 정확히 표기한다. **없는 데이터를 있다고 쓰지 말 것.**
