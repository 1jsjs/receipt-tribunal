# 제품 정체성 — 영수증 소비 재판소

한 달치 영수증 → 판결문 + 소비 유형 선고. MBTI식 재미와 재판소 콘셉트의 위트있는 톤이 정체성이다 (판결문·드립 문구 전부).

- 카테고리 6종 고정: 식비 / 카페·간식 / 쇼핑 / 교통·이동 / 여가·문화 / 기타. 이 밖의 카테고리 추가 금지.
- 판정은 subtype(배달앱/편의점/마트·장보기/카페/일반) 기반 조건문 룰 — LLM 판정 금지.
- 성공 기준: 더미 시드로 죄명 8종 전부 재현 / 수동 입력만으로 전 흐름 동작 / 데모 무중단.
- 하지 않는 것: 로그인, 계좌 연동, 예산 추천, 랭킹.
- 기능 추가 제안 대신 P0 완성도를 높이는 제안만 할 것.
