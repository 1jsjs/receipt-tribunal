# 제품 정의 — 영수증 소비 재판소

## 한 줄
한 달치 지출내역을 제출하면, 통장이 나를 고소하고 재판부가 판결문을 선고하는 서비스.

## 핵심 사용자 경험 (이 흐름의 자연스러운 연결이 최우선 목표)
지출내역 제출 → "어? 배달을 이렇게 많이?" → 재판 → "냉장고 유기죄ㅋㅋ"
→ 소비 유형 배너 클릭 → "ㅋㅋ루삥뽕" → ㅋㅋㅋㅋ

## 입력 경로 2가지 (둘 다 P0)
1. **파일 업로드** — 엑셀·CSV·텍스트 PDF를 올리면 거래를 뽑아 저장 (주 입력)
2. **수동 입력** — 한 건씩 직접 입력 (파일이 없거나 몇 건만 추가할 때)

## 화면 중요도 (큰 것이 위)
소비 유형 > 판결문 > 총지출 > 카테고리별 > 세부 통계
결과 화면이 이 서비스의 전부다. 판결문은 크고 눈에 띄게.

## 절대 제거 금지 (없으면 서비스가 아님)
파일 업로드 / 수동 입력 / 저장 / 월별 조회 / 수정 / 삭제 /
월간 분석 / 소비 유형 판정 / 판결문(죄명·증거·판결·이유·형량) / MZ 배너 클릭

## 톤
- 재판소 컨셉: 존댓말 판사 어조, 진지한 척하지만 내용은 웃김
- MZ 리액션은 반대로 완전 구어체 ("ㅋㅋ루삥뽕", "ㄹㅇ")
- 에러 문구도 서비스 톤으로 ("판결을 원하시면 소비 내역부터 제출하세요 👨‍⚖️")
- 판결 대상은 사용자의 소비 습관이지 사용자 자신이 아니다. 인신공격·죄책감 유발 금지

## 안 만드는 것
